# Militech-учебниый сайт

 Учебный проект

Сайт на HTML, CSS и JavaScript

## Страницы сайта

index.html - главная страница
about.html - информация о компании Militech
gallery.html - галерея

## Что есть на сайте

- Меню для перехода между страницами
- Галерея с переключением изображений
- Калькулятор стоимости перевода валюты
- Частые вопросы
- Форма обратной связи для примера

## Использованные программы и технологии

HTML
CSS
JavaScript
Git

## Как открыть сайт

Нужно открыть файл index.html в браузере
